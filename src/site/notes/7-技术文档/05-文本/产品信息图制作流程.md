## 生成产品介绍

把源代码传给千问，`开启深度思考`，使用下面的提示词生成产品介绍，`需要修改提示词底部的产品名称`



```markdown
你是一名资深产品文案与用户体验写作者。请基于我提供的“源代码（或代码片段）”，推断这是一个什么产品/功能，并写一份**面向最终用户**的产品介绍。你的目标读者不是开发者，而是普通用户、业务用户、消费者或企业采购方。

### 输入

我将提供：

* 产品源代码/仓库关键文件
* 可选：产品名称、目标人群、使用场景、竞品、定价策略（如果没有就自行合理推断，并明确标注“推断”）

### 写作要求（非常重要）

1. **禁止**：解释代码结构、框架、库、API、算法、模型、数据库、部署、性能指标、类/函数/变量等技术细节。
2. **必须**：用用户能理解的语言讲清楚“它能解决什么问题、怎么用、有什么好处”。
3. 先从用户价值出发，再讲功能点。每个功能点都要落到用户收益（节省时间/降低错误/更安心/更高效率等）。
4. 风格：清晰、可信、易读，可用于官网落地页/应用商店/产品手册首页。
5. 禁止杜撰代码中不存在的功能

### 输出结构（按下面顺序输出）

1. **一句话卖点**（≤20字）
2. **产品简介**（80–150字）
3. **适用人群/场景**（3–6条）
4. **核心功能与收益**（5–8条，每条=功能名 + 用户收益）
5. **用户使用流程**（3–6步，用“你可以……”叙述）
6. **为什么选择它**（3–5条差异化优势，面向用户表述）
7. **常见问题 FAQ**（5问5答，用户口吻提问）
8. **行动号召**（1–2句，偏转化）


现在请阅读我接下来粘贴的源代码，并按以上结构输出产品介绍。


----

目标用户：中小学教师
注意事项：不要提及任何与费用相关的内容
应用名称：{深度研究报告}
```

## 生成信息图

访问`信息图`工具。

1. 选择文本粘贴
2. 上传参考图，参考图如下

![image.png|650](https://nxl-tuchuang.oss-cn-beijing.aliyuncs.com/202512220950228.png)


3. 输入额外要求，如下

```
  1. 正式的
  2. 不出现人物，避免卡通化
  3. 不要出现二维码 
  4. 不要随意杜撰不存在的内容
```

4. 展现风格设置为“自动”，样式风格设置为“自动”，图片比例设置为“9:16”
